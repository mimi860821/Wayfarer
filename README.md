# iKiwi

An iOS app for simulating GPS location on-device (teleport, navigation along routes, multi-stop routes,
point-to-point hops, favorites and history). Install with SideStore. Requires a pairing file and
LocalDevVPN, and a connected Wi-Fi network (see the in-app guide for using it without Wi-Fi).

The kiwi is a bird that cannot fly: it gets where it is going on foot.
